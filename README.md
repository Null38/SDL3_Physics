# SDL3_Physics

# Celeste Physics

This repo is an attempt to recreate the physics of [Celeste](https://www.celestegame.com/), as described by Maddy Thorson, using [SDL3-CS](https://github.com/edwardgushchin/SDL3-CS).

The implementation is still rough and currently only includes basic player movement. Input handling is temporarily implemented using a hash set, there is no jump height limit, and various aspects, no solid movement, and no ground detection, still need improvement.

## Used

- [SDL3-CS](https://github.com/edwardgushchin/SDL3-CS) ([zlib License](https://github.com/edwardgushchin/SDL3-CS/blob/main/LICENSE))
